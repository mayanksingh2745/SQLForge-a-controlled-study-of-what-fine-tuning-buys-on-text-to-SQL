# SQLForge Research Reports

This directory stores evaluation tables, comparative summaries, and research figures generated from SQLForge experiments.

## Directory Structure
* `figures/`: High-resolution figures (e.g., execution accuracy vs LoRA rank, latency Pareto curves, error taxonomy distributions).
* Markdown summaries and generated model cards.

## Reporting Standards
* Every reported metric must state the evaluation dataset split, sample size $N$, and $95\%$ bootstrap confidence interval.
* Results must distinguish between Execution Accuracy (EX), Exact Match (EM), and Valid-SQL Rate (VSR).
